# Mr.Huang Agent 全程序 UI 重做计划（不懒小熊视觉世界 · 双主题同等）

目标：按「不懒小熊」品牌手册全面重做视觉世界——不是修补，而是替换单位：色板、明度阶梯、字体气质、图形语言、卡片形态在全部 11 个视图 + 15 个组件 + 壳层落地，浅色/深色两主题作为同等验收对象。业务逻辑、文案、Electron 特性（无边框拖拽、titleBarOverlay 安全区）不动。

## 第 0 阶段 · 视觉世界定案（先行，一次到位）
- 新建 `PRODUCT.md`（产品真相：各页面模式归属——工作台=Operate+Persuade、对话/群聊/写作/选题=Operate、智能体/技能中心=Operate、笔记库=Read）与 `DESIGN.md`（承诺新视觉世界，替代靛蓝旧世界）。
- **解决黑/灰/米断层**：侧栏由 `#101010` 改为暖调近黑 `#1b1713`（hue≈25 家族），三段表面同色相、明度节奏均匀（L10 → L93 → L96）。
- tokens.css 全面重写（双主题各自完整推导，非反色）：
  - 中性阶：全部 hue≈25 暖家族，侧栏暖黑 → 页面底 → 沉底轨 → 卡面 → 边框 → 文字，每级明度台阶均衡；
  - 行动色橙 #FF6A00 色阶、信息色蓝 #006BFF 色阶、语义色四对（实色+soft）；
  - 字体：新增 display 层级（页面标题 30px/字重 800，卡片标题 700）；
  - 图形语言令牌：几何点缀（圆点/圆环/叉号/波点 pattern）统一定义为可复用 CSS/SVG 组件；
  - 阴影、动效、圆角随新世界重校。
- 验收：tokens 层静态审查 + 一页试点（工作台）双主题截图确认后，再铺开。

## 第 1 阶段 · 壳层重做
- MainLayout（侧栏/顶栏/面包屑/Logo/抽屉）、ThemeToggle、UserAvatar。侧栏暖黑 + 橙选中态 + 白字；顶栏融入新阶梯；导航选中语言与手册"贴纸感"对齐（圆角胶囊选中块）。

## 第 2 阶段 · 通用组件与全局类
- base.css 全套（.btn/.chip/.card/.modal/.field/search-box/menu）按新世界重校；EmptyState 三套 SVG 插画按手册图形语言重绘配色（橙/蓝/暖黑）；StatCard、TaskRunCard、ToolStepCard、AgentAvatar/GroupAvatar/UserAvatar、各 Panel 统一过一遍。

## 第 3 阶段 · 11 个视图逐页重做（每页含双主题）
按依赖顺序分 4 小批，每批完成后立即双主题截图验收：
1. Dashboard + Settings（展示壳层气质的门户页 + 最复杂的表单页）；
2. Chat + GroupChat（核心操作面，延续沉底轨 + 内容区结构，气泡/输入区/composer 全部按新世界重做）；
3. WechatWriting + TodayTopics（向导流，阶段卡、状态徽标、选题卡选中态白卡+橙描边+徽标减量一并落地；公众号预览区保持纯白仿真）；
4. Agents + Skills + Vault + Tasks + DataCenter（工作台/网格/双栏/占位页）。
每页的验收标准：布局结构清晰、品牌图形语言可见（点缀几何、块状橙）、双主题对比度达标（正文 ≥4.5:1）、无叠层泄露/同色相消类缺陷。

## 第 4 阶段 · 总验收
- `npm run build` + `npm run lint` 通过；
- impeccable 机械检测（`impeccable detect`）跑一遍全部改动文件；
- 全部 11 页浅+深双主题截图，派 visual-judge 做一次批量视觉验收；缺陷一批修完，最多再确认一轮即收工。

## 执行方式与保障
- 每阶段派 code-agent 执行（任务书带全上下文与行号），阶段间我截图复检后再进下一批；
- 不改业务逻辑与文案；组件只引用令牌；每阶段 build+lint 必须通过才进下一阶段；
- 全程约 5 轮派发 + 2 轮集中验收，任何一轮发现问题当轮修完再前进。
